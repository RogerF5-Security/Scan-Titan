Flujo zero-touch

El operador prepara objetivos autorizados y ejecuta el lanzador. El resto se encadena sin preguntas.

01Entrada

Lectura sanitizada de objetivos y configuracion.

02Recon

03DAST

Payloads context-aware con validacion antifalso positivo.

04Externos

05Evidencia

06Reporte

Motores internos y externos

La arquitectura separa validacion propia, reconocimiento y herramientas externas para evitar reportes inflados.

Motor Python asincrono

Ejecuta modulos DAST con `aiohttp`, semaforos, jitter por payload y controles de pausa/reanudacion.

  • SQLi, XSS, LFI, SSRF, SSTI y Command Injection.
  • Autenticacion, sesiones, JWT, IDOR y rutas sensibles.
  • Fuzzing de rutas y endpoints con soft-404 filtering.

Nmap y Nuclei

Se ejecutan como procesos externos observables, sin limite duro por defecto, con heartbeat y salida parseada.

  • Nmap NSE: vulnerabilidades seguras, TLS, Slowloris y Vulners.
  • Nuclei: perfiles general, conservador y CVE.
  • Puertos del target y puertos descubiertos entran en los perfiles.

OWASP ZAP

Integra acceso de semillas, spider, pasivo y activo con control de estado, filtrado de falsos positivos y export JSON.

  • Sin reloj global cuando el timeout es `0`.
  • API local con autoarranque opcional del daemon.
  • Recon y alertas quedan separados.

Reconocimiento profesional

La inteligencia de superficie se mantiene fuera del listado de vulnerabilidades para que el informe sea defendible.
